# PR19_NavMeshAI

Откройте эту папку через Unity Hub → Add project from disk (Unity 6000.6.0f1).
Откройте Assets/Scenes/MainScene.unity и нажмите Play.

Выберите тип справа и нажмите «Создать врага». Space — создать, N — NavMesh,
T — сменить состояние всех врагов, Delete — очистить.
Игрок перемещается через Transform в Inspector во время Play, как в задании.
Ручное состояние удерживается 3 секунды, затем продолжается автоматический ИИ.
Атаки выводят сообщения в Console; здоровье игрока и снаряды не предусмотрены инструкцией.

Сохранены классы, структура ассетов, параметры врагов и основные элементы интерфейса.
Исправления: namespace Unity.AI.Navigation; слой Player и тег Enemy; неподвижные
точки патруля с привязкой к NavMesh; проверка точки создания; глобальные множители
применяются в AI; реальное отображение NavMesh; прозрачность фона для видимости уровня.
У капсул врагов pivot расположен на уровне пола, модель и коллайдер подняты на 1 м.

Assets/Editor/BuildPractice.cs воспроизводит сцену и ассеты (меню PR19).
Не запускайте повторную генерацию поверх вручную изменённых ассетов.
Assets/Editor/VerifyPractice.cs содержит проверку основных сценариев Play Mode.
